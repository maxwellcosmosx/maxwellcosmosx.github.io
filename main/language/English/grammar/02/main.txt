***虚拟语气***

虚拟语气常见的语法场景有:
1. If条件状语从句
2. 建议要求宾语从句

**If条件状语从句**
1. 与过去事实相反(过去条件+过去结果)
   If从句			主句
   had vp_pp.		would / could / might have vp.
   If I had studied harder, I would have passed the exam. 
   If I had had more time yesterday, I would have finished the project by now.

2. 与现在事实相反(现在条件+现在结果)
   If从句				主句
   过去式(be动词多用were)	would / could / might vp.
   If I had more time, I would learn Japanese.
   If I were you, I would accept the offer.
   
3. 与将来事实相反(将来条件+将来结果)
   If从句			主句
   (1)过去式			would / could / might vp.
   (2)should vp.
   (3)were to vp.
   If it were to rain tomorrow, we would cancel the picnic.
   If I should fail, I would try again.

4. 混合时间I类(过去条件+现在结果)
   If从句			主句
   had vp_pp.		would / could / might vp.
   If he had taken the medicine, he would feel better now.
   If I had studied medicine, I would be a doctor now.
   
5. 混合时间II类(现在条件+过去结果)
   If从句				主句
   过去式(be动词多用were)	would / could / might have vp.
   If I were you, I wouldn't have said that yesterday.
   f she were more careful, she wouldn't have made that mistake last week.

**建议要求宾语从句**
1. suggest, propose, recommend, demand, order, require, request, ask
   建议、要求： suggest + that + (should) vp.
   The doctor suggested that he (should) rest for a few days.
   The teacher suggested that every student (should) submit the assignment before Friday.

2. insist
   坚持要求(虚拟语气): insist + that + (should) vp.
   They insisted that she (should) attend the meeting.
   
   坚持声称(正常语气): insist that ...
   He insisted that he was innocent.
